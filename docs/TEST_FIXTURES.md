# 테스트 픽스처

VirtualBox 오프라인 탐색 기능은 사용자 VDI나 `%APPDATA%`를 테스트에 사용하지 않는다.
고정된 읽기 전용 이미지와 테스트 실행 중 생성되는 임시 VDI만 사용한다.

## 고정 NTFS 이미지

- 경로: `app/testdata/ntfs-testfs1.img`
- 크기: 2MiB
- SHA-256: `E3612C182B8010E3599B5EB93BFF427C7D824E85BDC2DDBE46E378E3BA814EB9`
- 용도: NTFS 3.1 루트 열거·숨김/시스템 속성·파일 스트림 읽기 검증
- 출처: `ntfs` crate 0.4.0 배포본의 `testdata/testfs1`
- 원본 이미지 자체는 테스트에서 쓰지 않으며, VDI 통합 테스트는 이 이미지를 임시 VDI
  컨테이너의 파티션 영역에 복사해 사용한다.

## 임시 VDI

테스트는 `GPUI_CONVENIENCE_TOOLS_DATA_DIR`나 사용자 데이터 루트가 아닌 OS 임시 디렉터리에
프로세스별 이름으로 VDI를 생성한다. 테스트 시작 시 바이트 스냅샷을 만들고, VDI 리더·파티션
검색·NTFS 탐색 뒤 동일 바이트인지 확인한 다음 파일과 부모 디렉터리를 정리한다.

손상 경계 테스트는 고정 이미지의 복사본에만 수행한다. 고정 원본은 변경하지 않는다.
