## 0. VirtualBox 오프라인 디스크 탐색·복사 — Phase O

### 범위와 안전 계약

초기 릴리즈는 **종료된 VM의 VDI를 읽기 전용으로 탐색**하는 것만 지원한다. 원본 VDI에는
어떤 쓰기도 하지 않으며, 실행 중 VM의 VDI를 직접 읽는 기능은 만들지 않는다. 실행 중 VM은
후속 `VBoxManage guestcontrol` 백엔드로만 검토한다.

현재 판단: Windows 게스트의 NTFS를 1차 파일시스템으로 지원하고, Linux 게스트의 ext4는
오프라인 백엔드가 안정화된 뒤 추가한다. 이 선택은 이번 기능의 필수 경로를 먼저 작게
검증하기 위한 것이며, `GuestFileSource` 추상화로 후속 백엔드를 막지 않는다.

### O-2. 읽기 전용 디스크 백엔드
