> 이 저장소에서 작업하는 모든 AI 에이전트(Claude Code, GitHub Copilot, OpenAI Codex 등)가 따라야 할 공통 규칙.

## 자율 판단 범위
- 환경 구축, 의존성 설치, 빌드 설정 등 되돌리기 쉬운 작업: 승인 없이 수행
- 아키텍처를 바꾸는 결정, 외부 API 계약 변경, 데이터 삭제: 반드시 먼저 확인

## 작업 시작 전
1. `PROJECT_MAP.md`로 관련 파일 위치를 확인한다
2. `ARCHITECTURE.md`로 해당 영역의 설계 의도를 확인한다
3. 관련 `tasks/TASK-*.md`가 있으면 먼저 읽는다

## 완료 기준
- `HARNESS_MAP.md`에 정의된 빌드/테스트가 통과해야 "완료"로 간주한다
- 완료 후 관련 `tasks/TASK-*.md`의 상태와 `MASTER_PLAN.html`의 단계 배지를 갱신한다

## 금지 사항
- 이 문서 6종을 임의로 구조 변경(파일 삭제·이름 변경)하지 않는다
- 테스트를 건너뛰고 "완료"로 표시하지 않는다
