# Project Docs — 저장소 연결

[문서 등록부](../../../docs/README.md)에서 책임을 찾고
[공통 지침](../../../docs/DEVELOPMENT_GUIDE.md#문서-작업의-최소-범위)을 따른다.
관련 열린 작업과 영향받은 절만 읽고 바뀐 사실의 정본만 수정한다.
문서 종류별 필수 세트를 만들거나 기존 문서를 재생성하지 않는다.

문서 형식 검사·내용 검토는 [검증 절차](../../../docs/VERIFICATION.md#문서-전용-검증),
협업 동기화는 [docs-sync 역할](../../../.github/agents/docs-sync.agent.md)이 정본이다.
전역 docs-canon을 사용할 때도 이 저장소의 배치·완료 게이트가 우선한다.
이 폴더의 assets는 구형 선택 예시이며 현재 정본 생성 규칙이 아니다.
