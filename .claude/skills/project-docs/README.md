# project-docs — GPUI 전용 연결

이 폴더는 이 저장소의 [문서 등록부](../../../docs/README.md)와
[공통 규칙](../../../docs/DEVELOPMENT_GUIDE.md)으로 연결하는 로컬 어댑터다.
다른 프로젝트의 전역 스킬로 복사하지 않는다.

전역 문서 작업은 docs-canon을 사용하고 기존 프로젝트의 정본 역할에 매핑한다.
기본 동작은 관련 정본 갱신이며, init/문서 세트 재생성을 자동 수행하지 않는다.
assets는 과거 선택 예시로 보존했으며 현재 작업의 필수 템플릿이 아니다.
